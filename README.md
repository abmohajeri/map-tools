# Map Tools

**Map-Tools** is an online map assistant that provides utilities such as geometry extraction, geometry viewer, and coordinate conversion. Whether you're a GIS professional, developer, or anyone working with spatial data, this tool makes these tasks easier and more efficient.

## Features

- **Geometry Extractor**: Draw Points, LineStrings, Polygons, and BBoxes, then export them as a coordinate Array, WKT, or GeoJSON in EPSG:3857 or EPSG:4326. Drag vertices to edit after drawing (Esc cancels a sketch, Backspace removes the last point), see live length/area measurements, and jump anywhere with the built-in location search. Copy or download any output as a file.
- **Geometry Viewer**: Paste — or import a file (file picker or drag-and-drop) — a coordinate Array, WKT, or GeoJSON (format and projection are auto-detected), visualize it on a map, inspect its measurements, and convert it between all three formats with one-click copy or download.
- **Coordinate Converter**: Convert a coordinate between EPSG:3857 and EPSG:4326 — the source projection is auto-detected, and Enter converts instantly.
